# 工程决策与已验证问题

本文件仅记录本仓库的事实，不修改用户提供的规则模板，也不写入全局 Codex 记忆。

## 文档与运行状态分开

日期：2026-10-13。编辑器持久化 `.rea.json` 文档；运行时持有独立变量、元件覆盖及中继器数据。预览后的表单/面板变化不能污染设计文档。重启销毁旧运行实例并取消等待链，重新执行页面与元件加载逻辑。单元和浏览器回归覆盖这些行为。

## 预览和离线导出复用运行时

独立运行时与表达式解释器均能通过 `toString()` 序列化，依赖只通过参数显式注入。这样不会依赖压缩器保留模块变量名。单元测试在隔离 VM 实例化，生产 E2E 则从真实构建页面导出，再在断网 `file://` 环境执行。

不得用 `eval`、`Function`、HTML 拼接或任意属性访问代替受限表达式解释。输入中的 `[[...]]` 只做一轮替换，来自表单、变量或行数据的结果不再次作为代码/表达式解释。

## 离线 DOM 按实例键复用

初版为所有鼠标事件重绘整个页面，造成进入元件→销毁 DOM→再次进入的循环，真实点击测试失败。修复为忽略无处理器事件，并按实例键复用元件/输入节点。鼠标操作和表单焦点不能依赖 force-click 掩盖问题。

## Electron 输入弹窗

真实桌面进程验证确认 `window.prompt()` 抛出 `prompt() is not supported.`。使用统一 React DialogProvider 替代输入弹窗；浏览器与桌面都测试 OK/Cancel。仅有浏览器端到端测试不能证明 Electron 原生功能可用。

桌面启动、重命名、保存/打开、HTML 导出和实验性 RP 导入使用真实 Electron 测试。自动化仅替换 OS 文件选择器的返回值，后续 preload、IPC、验证、原子写入、读取与解析仍走真实实现；这不等于已自动操作系统文件选择器本身。

## 中继器运行时实例

原先仅按模板元件 ID 存储覆盖值，导致一行输入会更新所有行。修复后每个运行时数据行分配稳定 ID，按完整父级行上下文和元件 ID 存储覆盖；不把数据内容或显示位置当作身份。重复内容不会交换状态，删除会清理行与嵌套数据，新行不继承旧身份。动作失败时数据、ID 计数和覆盖一起回滚。

内部动作匹配共同的父级行；作用于自身模板时只修改当前行，作用于当前行内嵌套模板时覆盖其子行。外部动作可修改全部现有实例，新增行仍从文档模板开始。预览与独立 HTML 使用同一上下文 API；普通绘制不移动已在正确位置的 DOM 行，避免输入失焦和 change 重绘循环。测试先在修复前复现污染，再验证预览和真实离线导出。

后续静态分析纠正了“排序/筛选保留临时状态”的早期实现：原版普通刷新重建模板，临时输入、选中和面板状态复位。当前数据身份仍稳定，但每次刷新增加呈现版本并清理行控件覆盖，再逐行执行 Item loaded→子控件 Loaded。持久值通过更新 dataset 再绑定恢复。隐藏控件、非活动面板状态也参与初始化。单元测试与预览/真实离线导出已按此修正，不能保留旧断言作为原版一致性依据。

行更新先选中所有目标，再逐列遍历全部目标行；不是每行依次更新全部列。Item 优先表示事件源行，TargetItem 表示目标行。匹配规则扫描隐藏行；同一中继器同步刷新中的数据操作被忽略以避免递归。当前在同步阶段尾合并刷新；原版生成的刷新伪动作位置与 adaptive persist 尚未实现。证据见 [生命周期研究](../research/repeater-lifecycle-evidence.md)。

Wait（包括 0）把动作链分成同步阶段，计时器不占用全局事件队列；同一事件的后续独立条件分支在前缀完成后立即求值。Item loaded 的 Wait 不占有刷新保护栈，因此后续行继续加载，延时恢复可再次修改数据。每段分别记录回滚快照，延时失败不覆盖其他事件已经提交的值。页面切换提交和 dispose 取消旧页面任务，失败导航在提交前可回滚。源行删除后取消其任务是本应用稳定行身份策略，不声称与原版位置 ID 完全相同。见 [调度静态证据](../research/wait-scheduling-evidence.md)。

快照式运行时帮助函数也委托给同一独立运行时，避免编辑预览与导出维护两份动作逻辑。

## 标记行与分页

标记集合独立于控件 checked/selected，按稳定行 ID 存储。Mark/Unmark 本身不刷新模板，允许 Item loaded 内执行；普通刷新保留标记并重建控件，需由 Item loaded 的 Set Selected 表达式恢复勾选。新增行未标记，删除同时清除标记。匹配与 Marked 选择扫描所有源行，包括被过滤及其他页。Item.isMarked 与 Item.Repeater 元信息在事件触发时快照，TargetItem 同名路径动态读取；普通列值仍读取最新数据。Set Selected 作者入口新增单一完整表达式，原生 RP importer 仍仅接受严格字符串枚举。

分页可选字段缺省不写入，不改变旧文档。模型允许 1..10000 的有限小数，编辑器与运行时按原版 start/end 范围逐项取行，不用 slice 隐式截断。无效小数索引或非有限运行页大小返回明确错误；动作回滚，初始错误允许通过有效翻页恢复。原版边界崩溃不作为产品行为复制。

过滤后的 itemCount、visibleItemCount 在刷新提交时固定。Set page 按此前已提交 itemCount 限幅，源 dataCount 可即时变化；最终刷新才写回超限页修正。避免“删掉末页→同链补一行”或“临时过滤→清除过滤”错误地永久退页。不限→有限恢复页 1，有限→有限保留页码后限幅；无变化的翻页仍刷新。有效小数的实际行数与原始 end-start 可不同，isLast 按已取证的原始数量计算。

页面提交导航重新建立目的页的控件覆盖、数据、排序/过滤、标记、分页及嵌套实例；全局变量保留，旧行上下文失效。返回页面不能保留上次临时按钮文字或中继器数据；旧浏览器断言已按此修正。原版完整导航竞态、adaptive persist 与生成器精确刷新位置尚未复现。证据见 [标记行](../research/repeater-marking-evidence.md) 和 [分页](../research/repeater-pagination-evidence.md)。

## 命名查询规则

四个新动作 addFilter/removeFilter/addSort/removeSort 使用独立严格 JSON carrier，不迁移旧 filterRows/sortRows。初始化由 Loaded 动作表达，不臆造未证实的初始规则字段。编辑器校验真实目标列、额外键及数据类型；名字允许空串/空格、区分大小写，不插值。新筛选表达式必须为单个完整 [[...]]，内式最多 4096 字符；复杂 Widget 引用的克隆/组件同步只改表达式内非引号 token，不改规则名称或字符串字面量。

运行时筛选按有序数组存储，允许同名；最后规则决定 All/Any/Smart。Smart 同列内 OR、列组与无列规则之间 AND，按原顺序短路。添加规则不求值，排队刷新后读取最新变量与控件；字符串结果仅精确 true 通过。原字符串包装层捕获的求值异常在本解释器映射为不通过，不扩大为所有原生上下文异常都被吞。规则上限各 100 条，坏 payload 走动作回滚。

筛选源位置依原版保存添加者数字行地址，后续按当前源数据位置重取，不能以稳定行 ID 替代。源列缺失时 Item 回退候选列，TargetItem 总是候选；源越尾的列值失败，元信息仍属于该 repeater。This 支持 text 和五项 repeater 计数。过滤期元信息使用全源未排序数据及当前页窗口，visibleItemCount 仍为上次提交行数；完成过滤、排序后才提交最终页与计数。

排序按列替换并移动到最高优先级，Toggle 读取被替换规则旧方向；名称只用于移除。独立实现递归合并顺序以匹配原比较器的非对称数值/自然顺序 ties；仅转换前文本相等进入旧规则。日期按分隔符及数字部件验证，不使用 Date.parse；保留已证的分数月份/日期与非有限年份边界。旧筛选额外 AND、旧排序作最低优先级是兼容约定；全部移除/替换其他规则会清除旧规则。详见 [取证报告](../research/repeater-query-evidence.md)。

空回调采用独立 EventFrame.emptySource，不向 RowContext、dataset、DOM 或尺寸表插入假行。旧计数从 committedItemCounts 与动作后分页配置取得；原内部分页计数用 page×size 而非可见窗口的 (page−1)×size，所以最后页清空不触发。刷新到零并满足旧>0/新=0时，先分发 Item loaded，再请求模板普通控件/所有面板状态 Loaded；不初始化不存在的内层数据实例。嵌套保留外层 scope 用于目标隔离与 Wait 有效性，但其空 Item 映射只是本产品扩展。内部 Before Item Load 不作为新用户事件入口，Item Resized 由后续真实布局阶段实现，不对零行合成触发。证据见 [空数据报告](../research/repeater-empty-evidence.md)。

## IF／ELSE 条件链

`Interaction.isNewIfGroup` 为显式布尔扩展：true 开新链，false 接该事件前一链，首 Case 隐式开链。缺省按 true 处理，仅为兼容早期 `.rea.json` 的独立 Case 行为；原版生成数据缺省为 falsy 的规则不同，未来 RP 交互转换必须显式规范化，不能直接复用此缺省。

每次事件新建选路状态，先识别包括禁用 Case 在内的边界，再跳过禁用/未命中分支。第一个命中分支即占用该链，动作数组为空或遇 Wait 都不重新选路。All／Any 用有序短路求值，避免不需要的后续表达式错误。页面帮助函数通过 triggerPage 派发完整事件，不能拆成逐 Case execute 而丢失分组。

UI 按事件展示链，新增/复制后续分支明确写 false，新 IF 写 true；旧字段未设置的 Case 仍各自独立。上下移动交换 Case 内容但保留位置的组边界，删除/移走组首时提升原后继，改事件的 Case 自身开启新组。这些是当前可说明的编辑约定；原版的重排/删除修补算法没有运行证据，不宣称完全一致。无条件分支遮挡后续分支时显示提示，不自动删除用户数据。

官方多无条件 Case 的选择菜单受生成器设置控制；观察、来源与 unknown 见 [条件链证据](../research/conditional-case-evidence.md)。

## Case 菜单与兼容设置

`Document.caseSelection` 为 auto/always/never，缺省不补写。新工程明确 auto，旧工程缺省解释为 never，保留原有自动执行行为；这是项目兼容约定，不代表已经证明原版生成器的出厂默认值。设置经模型边界校验、保存/重开、撤销/重做，并应用到预览和离线 HTML。

菜单按源元件及完整稳定行上下文替换，不按事件区分；其他源菜单保留。无条件选择直接执行所选动作，条件模式用单个 Run event 入口重新判断完整事件，保留触发时 Item 显示快照并实时读取数据/变量。菜单不占执行队列，选项的 Wait 也不阻塞其他事件。初始化 Page Loaded 直接执行，widget Loaded 和 Item Loaded 仍走菜单策略。独立快照帮助函数只做非交互计算，明确绕过菜单。

菜单令牌属于当前运行会话；选择后失效，页面提交导航、dispose 或源行删除使旧选择失效。Cancel/Escape、键盘焦点、上下边界限制和失效源清理是本应用的无障碍/防错约定。Run event 简化了原版包含各 Case/action 的组合说明。没有外点自动取消，避免破坏原版已有的多菜单并存语义。原版错误/重入/导航竞态尚未动态验证，证据见 [菜单研究](../research/case-selection-evidence.md)。

## 组件与自适应数据

联动组件通过透明 panel 实体化，并记录源到实例 ID 的映射。克隆定义/实例必须重映射动作、条件、状态和内部引用；脱离必须移除链接字段，不能只传一个省略字段的 merge patch。

早期工程的自适应视图直接继承 Base，使用 max-width 选择；该旧格式继续兼容。后续新页面加入宽高选择和父链继承，本阶段再加入项目共享集合、各页独立覆盖和状态效果整图继承。文字/备注/交互仍共享。当前规则及边界见 [共享视图与行为说明](../research/adaptive-behavior-implementation.md)，不声称已重建 Axure 全部继承语义。

## 原生 RP 导入是显式子集

四个自写 Node 解析模块提供容器→对象→交互树与受限语义读取；没有加载或执行原 DLL。依据明确类型、本地几何或唯一完整缓存链生成控件，缺失坐标不猜成零。自动文字尺寸元件可恢复存储矩形并报告为冻结快照。Fit 面板要求所有状态内容完整、无未知阴影/自动文字尺寸；预览按活动状态可见孩子 right/bottom 重算，初始编辑矩形由首状态计算，零内容在 runtime 为 0×0。

桌面在有时间和内存上限的 Worker 中读取原文件，结果在转换边界再次验证；导入报告分别计数页面元件、面板状态、状态内元件、成功/跳过事件、Case、动作和变量，并披露样式恢复来源及未映射字段。已恢复基础颜色、字号及四角圆角；固定尺寸面板仅在完整状态引用和几何满足边界时恢复，循环、重复和深度超限拒绝。无可用元件时不覆盖当前工程。研究数据、原厂程序和静态 CIL 证据不进入发布包。

交互引用按包限定，不能将不同包中相同 GUID 合成一个全局对象。先完成几何转换，再映射 Case/action 的实际目标；任何一处不支持时整事件拒绝，避免丢掉 IF 却保留 ELSE。损坏树单独计数，不能伪装成零事件成功。配置字符串使用自定义转换；目前只承认四个官方样本与元数据双证的 DisplayMultipleTargetsOnly→auto，未知设置阻止交互恢复但仍保留几何。

`Condition.comparisonMode='axure'` 只允许 equals/notEquals。它明确实现原生字符串子集的 getBool→等值语义：忽略大小写的 true/false 转布尔，混合布尔/字符串按数值比较，其他两个字符串保留字面比较。不执行原版 JS；导入的表达式分隔符字面值目前拒绝，避免被误当成 REA 表达式。无该字段的旧条件维持原语义。Focus/Blur 只绑实际表单控件；菜单自动聚焦与焦点恢复期间抑制这两种事件，真实点击/Tab 正常执行。

图片从同一个不可变对象包的明确 IMAGE Stream 范围读取，核对源摘要和受限 PNG 结构后嵌入工程；不将缩略图或 Hash 字符串猜作原图。单图 4 MiB、累计 data URL 8 MiB，并限制尺寸和解压长度。只有明确的等比例矩形、无已知裁剪/滤镜/变换的 PNG 才进入模型。来源报告省略重复 data URL，保留摘要、尺寸与范围。限制和样例见 [图片证据](../research/axure-image-recovery.md)。

## 打包与验证环境

内联框架使用独立变量和控件状态，作者画布仅显示静态预览。内部播放通过真实 iframe 隔离，不授予 same-origin 或桌面 API；preload 与 IPC 同时要求主框架身份。打包验收确认 opaque file 文档不能读取第二个本地脚本，也不能再次加载嵌套本地播放器，因此固定播放器将脚本内嵌并使用构建哈希 CSP；子级复用同一模板及脚本哈希，按来源和随机令牌完成一次初始化。开发与生产共用构建函数。外部页面仍遵守浏览器嵌入策略，目标文件不自动进入发布包。详见 [框架实现说明](../research/inline-frame-implementation.md)。

选中状态保留底样式与 selectedStyle 叠层。普通控件 selected 与表单 checked 分开，原版程序 radio 赋值只清 peers.checked，不分发其选择事件；runtime override.selected 单独保留表单事件/样式状态，不写入原项目 schema。真实点击按原版先清具名 radio 组全部成员，再选择当前项；已选 radio 的 Space 没有原生 click，指针重复 click 则会触发清除/重选。禁用普通控件忽略赋值，原版程序表单赋值可改 checked 而不改变样式/发事件。同步事件按 selectedChange→select/unselect，循环设深度/次数上限。

selectionGroup 与 radioGroup 是独立命名空间，区分大小写；模板按行隔离是当前产品约定，原版 isolateSelection/isolateRadio 两开关仍未映射。Set Selected 容器递归传播尚未实现，因此 schema、Inspector 与原生 importer 都拒绝 panel/repeater 目标。状态样式盖过底层 setStyle，取消后显示底层修改。依据见 [选择证据](../research/rp-selected-state-evidence.md) 和 [布局证据](../research/rp-selection-layout-evidence.md)。

原生导入将分组身份与外观恢复分开记录，即使某元件未导入，也必须参与源页面的组完整性审查。该审查跨所有面板状态包，不能只检查动作的显式目标；组不完整时原子拒绝相关事件，防止保留的 Tab 选中后与冻结的 Tab 同时呈蓝色。缺失/非数组的 Selected Style PropList 不等同于显式空数组，Set Selected 的布尔值也不自动转换为字符串。

使用 `@electron/packager` 的具名 `packager` 导出。版本由实际安装的 Electron package.json 读取，优先复用原始 ZIP 缓存，避免此环境直接访问 GitHub 超时导致重复下载。

本机存在 HTTP/HTTPS 代理；Playwright 的 localhost 健康检查必须对本进程补充 NO_PROXY。Electron 隐藏窗口测试关闭后台节流，并在 `invalidate()` 与两次绘制帧后调用 `capturePage(undefined,{stayHidden:true})`，避免截图超时或返回上一幅已缓存画面；不为测试弹出窗口。

仓库创建时目录没有 Git 元数据；没有修改其他仓库历史。检查代码变更应使用本工程文件及测试，不把未初始化 Git 的空输出当成“无修改”。

空 Item 字符串读取区分三类：未提供 action target 时抛内部 UnavailableItemError并仅保留失败的插值片段；普通控件 target 的 valid=false、缺失叶元信息是 undefined；真实目标行读取当前列/索引。缺失父对象和无有效行的数据列同样保留片段。受限表达式 provider 允许 string|undefined，undefined 的布尔值为 false，字符串转换为 undefined，数值转换继续显示受控错误；不引入 eval、任意对象或原 STO 类型系统。This.Repeater 同时支持 repeater 本体和普通模板控件所属 repeater，不依赖有效 Item。一般表达式错误不被这个空 Item 恢复路径吞掉。

每个模板目标独立解析动作值，SetVariable/Wait 没有伪造 target。无同行源时用 committedVisibleRowIds 枚举原生当前登记的显示实例；排队中的 filter/page/data 修改不能提前改变当前事件的目标集。同行显式 ID 选择仍保留。字段由 ensure/flush 更新，并参与事务回滚和实例清理；无显示行的目标动作不求值、不创建 overrides。数据增删改/mark 的行选择器是独立的源数据操作，继续覆盖隐藏行。

隐藏 Electron 测试新建 BrowserWindow 后，必须先 loadURL('about:blank') 让 Playwright 附着并产生 window 事件，再挂页面错误观察器并加载实际导出 HTML。仅 new BrowserWindow 而等待 window 会超时；已在空数据发布版 smoke 中复现并按此修正，复跑完整流程通过。

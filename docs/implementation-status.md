## 已验证的边界

输入框已接入 11 种类型、浏览器值规范、独立 Hint 状态及本地文件选择，贯通作者界面、预览、保存和离线导出。数字/日期的非法值、Set Text 事件判断和条件读取按实际控件值处理；文件选择不写入工程，不上传。原生容器恢复新增一个实际 Phone 字段，File 仅接收严格空初值子集。原版完整生成器与 GUI、原生 min/max/step 默认参数、移动键盘及日历/时钟弹窗仍未完成对照。见 [本阶段范围](../research/input-types-implementation.md)。

表单新增只读、输入框最大长度、回车提交绑定与 Set focus/Select text，贯通编辑、保存、预览和离线 HTML。原函数确认的两轮 Focus 与中间 Blur 按同步顺序执行；Wait、导航、递归保护和行定位均有针对检查。真实原生库新增恢复四个只读输入；所有真实 SubmitButton 均为空，非零绑定仍不恢复，四个原生 Focus 所属事件仍整体不受支持。隐藏字段的临时选区、Layer/RDO 代理、非表单原版 tabindex、移动端与完整原版 GUI 对照仍缺失。见 [本阶段范围](../research/form-properties-implementation.md)。

自动化检查覆盖主要模型与运行行为、真实浏览器编辑和文件往返、完全断网的 HTML 运行、开发版与生产版导出一致性、桌面进程启动和预加载 API 隔离。当前尚未把原版 Axure 与本应用逐项并排运行，因此不能从本应用测试通过推导为与 Axure 全部行为一致。

测试验证的是实际动作与最终数据，不以画面存在代替功能完成。原型重启应重新执行加载逻辑，旧会话的等待动作不能污染新会话；用户输入中的 `[[...]]` 保持字面文本；无动作鼠标事件不得反复创建 DOM。

条件链按元件/页面与事件分别执行：禁用的 IF 仍建立链边界，命中无动作或等待分支仍结束同链选路，其他独立 IF 继续判断。预览、序列化离线运行时和页面快照帮助函数共用规则。Case 排序保留现有位置的组边界、删除组首提升后继等是本应用当前编辑约定，原版这些编辑手势尚未完成动态对照。见 [条件链研究](../research/conditional-case-evidence.md)。

菜单策略已覆盖 Automatic/Always/Never、无条件单项选择、条件事件入口、同源替换与跨元件/行并存。初始化 Page Loaded 绕过菜单，控件和 Item Loaded 使用普通策略。条件选择保留原事件 Item 显示信息，但读取最新变量与列值。旧文档无设置时直接执行；非交互快照帮助函数也直接执行，不返回不可使用的会话令牌。Cancel/Escape/键盘、删除源行时清理菜单和 viewport 限制是本应用的扩展；原版富描述菜单、完整生成器选项及 GUI 差分仍未完成。见 [菜单研究](../research/case-selection-evidence.md)。

命名筛选支持重复名称、按名删全部、最后规则决定组合、变量/This.text 在刷新时重读。行内添加的规则保存源数字位置地址；删行可能使 Item 改指后继，越尾的列值求值失败但 Repeater 元信息仍可读。过滤期 Item/TargetItem 显示索引与计数基于当时未过滤、未排序的全源数据，之后才排序和分页；此处并非最终结果索引。

命名排序按列替换、后添加优先，7 种类型及转换前文本相等的次级排序边界已对照原函数输出；自然顺序受宿主 locale 影响。新规则的字符串表达式失败按不通过处理，不声称覆盖完整原生 STO/localVariables 异常边界。每个实例最多 100 条筛选及 100 条排序。旧单条规则继续保留；混用时旧筛选为额外 AND、旧排序为最低优先级，这是本应用兼容约定。研究与可复现实验见 [查询规则](../research/repeater-query-evidence.md)，演示见 [工程](../artifacts/repeater-query-demo.rea.json)。

已接入顶层空数据回调，使用原版内部旧/新计数及分页条件；真实数据行、DOM 和尺寸记录不增加哨兵。模板子 Loaded 及面板全部状态仍可执行外部动作，This.Repeater 独立读取所属中继器；同步自数据操作受 guard 保护，Wait/Case 菜单保留无效 Item，页面离开取消旧等待。模板目标枚举当前已提交显示行，数据行增删改选择器仍可扫描隐藏源数据。Item Resized 已接入真实行尺寸变化；嵌套空事件为本产品扩展，原版完整 STO、富文本动作和生成器刷新位置仍未覆盖。见 [空数据证据](../research/repeater-empty-evidence.md) 与 [可编辑演示](../artifacts/repeater-empty-demo.rea.json)。原函数隔离实验未替代原版 GUI 对照。

追加证据分为 [源与目标作用域](../research/repeater-empty-scope-evidence.md) 和 [字符串求值](../research/repeater-empty-string-evidence.md)。前者核对无 DOM 子 Loaded、可见目标集合及内部事件边界；后者核对逐插值失败回退、逐目标参数求值、目标恢复和 addRow 容器求值。未注解或手工注解的 AST 仅证明对应原函数行为，不能当作原编译器的实际输出。

显示缩放会改变浏览器实际边框宽度，CSS尺寸读回还会舍入。运行时和静态行原点使用浏览器实测盒模型；CSS原始赋值与几何缓存分别保存，避免将读回的舍入值重复写入。没有浏览器的模型调用使用逻辑尺寸回退。小数行尺寸及多行推移现分开保留名义尺寸、CSS赋值和几何读回；初始包络及逐次加法顺序也与原函数一致。真实宿主100%/150%下的20个场景、188次尺寸调整已逐项比较CSS字符串、名义表、几何/位置缓存和事件次数；普通刷新恢复初始raw缓存。详见 [行量化研究](../research/repeater-row-quantization-evidence.md)。原版默认box-sizing、预生成行、复杂adaptive、跨显示器/zoom、嵌套fit重入及动画仍有对照边界。

# 选择控件 Windows 候选版

本阶段把已完成的选择控件布局、作者属性、尺寸手柄、修饰键输入和多选旋转纳入同一 Windows 候选程序，补充全量浏览器回归与实际打包程序检查。产品版本仍为 `0.1.0`，这是本地开发候选版。完整 Axure 复刻、原版 GUI/像素一致性和原生 `.rp` 写回均未完成。

## 候选内容与来源

- 程序目录：`.build/selection-delivery-package/REA Prototype Studio-win32-x64/`。
- 程序主体 `resources/app.asar` SHA-256：`604c4ada82c9d3e61eb37a521f1dd732377bd63d7827bd0631c027c5d60e41cd`。
- 使用旋转阶段冻结的 `.build/selection-layout-rotation-final-dist`；本阶段未改产品源码、桌面主进程或原生读取器。
- `selection-controls.rea.json` 是独立创建的演示工程，带明确的选择控件文字布局声明和支持的纯色描边。打开后可验证单体水平缩放、多选 Ctrl 手柄旋转、撤销、文字适应与指示器左右位置。
- 配套说明更新了当前行为与边界，并将原生样本的 Layer 数量从旧阶段的 182 校正为当前 192。旧说明和首个示例的字节另行保留。

包内 20 个应用文件/条目已与冻结构建、当前桌面代码和五个读取器逐一核对。22 款 Roboto/Open Sans 字体保留 Apache 2.0 许可与声明；没有打入 Axure 专有代码或资源。旧发行 ZIP 与旧 `app.asar` 保持原字节。

## 保留的失败与处理

1. 首次原生导入脚本仍断言旧 Layer 阶段的汇总字段，在启动应用前失败。第二份脚本改用当前冻结的十样本文档对照数据；完整文档与重开检查通过。首份脚本、日志和失败报告保留。
2. 首个选择控件演示工程继承了透明底色、零描边，因此落入现有兼容绘制路径，不能断言独立文字测量已就绪。当前示例明确指定白色底色和 1px 实线描边；产品默认值未改。这一限制仍属于未覆盖范围。
3. 第二次桌面专项把请求坐标当作 Electron 最终事件坐标，导致网格旋转的 `x` 相差约 `0.00000160848`。实际捕获的图面 `y` 为 `309.5000305175781`、`342.0000305175781`、`324.0000305175781`，分别与请求值相差 `0.000030517578125`。第三次脚本记录实际事件，并送入独立的保留 CIL 指令解释器，结果在原有 8 位小数比较精度下通过；没有改产品代码或放宽容差。原请求失败、事件序列和指令回放均保留。
4. 既有桌面批次首次为 13 组通过、1 组失败：Layer 样式脚本仍预期 Prototyping Basics 恢复 171 个、跳过 25 个控件，而当前冻结对照记录是 172/24。单独保留的修订脚本从该对照记录读取计数，并额外比较整个导入文档；原有作者预览、离线交互与原生悬停断言全部保留，最终通过。首次批次记录不覆盖。

指令解释器仍使用明确的运行库与绘图/通知替身；未加载或执行原厂 DLL，不能替代原版运行实测。

## 证据保全与交付边界

浏览器与桌面旧脚本会写入部分历史路径。每个批次先备份原字节，将本次产生的不同文件保存到独立目录，再恢复并验证原文件。原旋转阶段的证据、源码快照和两个旧发行文件分别核对，不覆盖历史验证结论。

候选压缩包单独写入 `release/candidates/REA-Prototype-Studio-0.1.0-selection-candidate-win64.zip`。ZIP 内每个条目的哈希均需匹配实际通过检查的候选目录，归档后再次确认目录未变化。它不替换原发行版，也不表示发布或完整验收 Axure 等价性。

仍缺少原版 GUI/字体/像素直接对照、完整创建与默认/状态行为、一般坐标变换、混合控件与递归分组作者操作、引导线/对象吸附及完整按键派发。原版截图/输入桥接故障未解除；原生格式仍为实验性只读导入，保存使用 `.rea.json`。

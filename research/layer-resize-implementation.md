# Layer 作者缩放与约束

本阶段实现组的八向尺寸手柄、Group width / Group height 输入，以及水平/垂直 pin、固定宽高的保存、继承和原生导入。它扩展上一阶段的真实嵌套 Layer，不把组重新解释成改变成员坐标原点的容器。

## 已接入的行为

- 从拖动开始时的有效视图快照计算每一帧；一次手势对应一次撤销。Escape、取消指针或切换视图/编辑范围会恢复开始时的文档。多组选中拖动使用共同选择框，锁定的选中组参与该框但不写入。
- 侧边手柄按原入口的单轴自由度运行，角手柄使用双轴。跨过对边的原始位移先按旧选择框限制；无法由当前正尺寸模型表示的结果整次拒绝。
- 组内先处理接触边界的成员，再以候选边界处理其他成员。嵌套组、成员旋转、pin、已表示的 AutoFit 标志及锁定上下文使用保留源码所确定的顺序。
- 缩放几何仅写当前视图，即使勾选 Affect all views；AutoFit 等共享内容仍保持共享。组中的普通成员保留完整位置/尺寸属性对，其他局部及非活动视图声明不变。
- 多组手柄使用共同选择框。多组 Inspector 数值输入则分别设置每个组的自身目标宽高，这是已测试的产品约定，尚未建立原版多选数值界面的完整合同。
- Pin 控件编辑四个独立作者字段，并遵循普通当前/所有视图规则。它们不进入状态效果、富文本、提示样式或 Set style 的视觉字段集合。

支持的成员包括已闭合的普通形状、图像矩形及普通表单等类型和嵌套 Layer。组位于面板或中继器编辑范围内时，仍使用该范围的局部坐标；这不代表已支持缩放作为组成员的面板或中继器本身。

## 原生格式与数值证据

原生 P106/P107 为水平/垂直位置约束，P108/P109 分别为固定高/固定宽。保留的初始化指令给出 None、None、false、false 默认值；有效覆盖链和明确无链接样式分别验证。导入保留显式本地 None/false，不给所有旧对象展开全套默认字段。

11 份原始样本中，原先可导入的 10 份全部保留，原先超页面上限的一份保持同一拒绝。新增保存 2,308 项约束；删除这四类新字段后，完整文档与上一版严格相同，10 份文档保存重开一致。实际 Windows 包另通过四份原始工程的 IPC 导入、完整模型比较和重开，保留 182 个完整组及 13 个组交互。

静态证据包括 5,004 项数值对照、142 项控制器分支、64 项能力分支与 6 项掩码不变量、23 项属性解析/default 检查、54 项入口指令检查。最终独立复核有 179 项，其中 30 项验证产品对不满足当前正尺寸模型的结果的明确拒绝。不同检查族存在重叠，不将其相加冒充原版画布测试。

作者外框与缩放快照共用已证尺寸边界函数，包括接近 1° 的源代码特殊分支。此前通用旋转外框的偏差已保留为红测；修正后 60 项相关模型/运行时检查通过，原始样本完整文档回归仍仅增加 pin 字段。

## 验证与保留记录

当前已通过 4,712 项单元测试、841 项原生读取测试和类型检查，检查期间输入哈希不变。实际 Windows 候选已完成缩放、固定宽、撤销/重做、取消、保存重开、预览及离线导出；七张实际窗口图片已经逐一查看。

生产浏览器全量回归已通过 332 项，无跳过、失败或不稳定项。13 组实际 Windows 包检查全部通过，覆盖新增缩放、四份原生工程完整模型导入，以及已有组合动画、旋转、矢量轮廓、中继器布局/分页、文字自动尺寸、内联框架、自适应全视图编辑、嵌套组与组交互样式。所有脚本均核对同一候选包的 `app.asar` 未改变；浏览器和打包回归产生的历史路径替换文件分别留存，并恢复原有证据字节。

发行过程保留上一版源码、程序和 ZIP；最终归档中的每个文件与已测试候选逐项比对。发行结果和实际包哈希以 [发行验收记录](layer-resize-verification.json) 及 `release/verification.json` 为准。这些结果证明本产品的已列测试通过，不代表原版画布或逐像素一致。

首次界面验证暴露侧轴和多组选择框偏差，均已按原入口指令修正。首次构建及其全部 128 项输入可回溯，旧源码、失败日志、修正后的独立对照均保留。开发服务器加载超时、测试夹具前置和“同值输入未触发真实输入事件”也单独保留，不混为产品缺陷。

# 移动、尺寸、旋转组合与拖拽

本阶段为独立产品加入结构化 Move / Set size、多目标顺序、每个表达式的局部控件绑定、边界条件与拖拽输入。普通目标的 Move / Resize / Rotate 共用按通道和时长切片的运行队列。预览、离线主页面及内部框架使用相同核心。完整 Axure RP 11 等价仍未实现。

## 作者入口与保存

Interactions → Move 可选择 To、By、跟随拖拽、拖拽前位置、跟随来源移动或尺寸变化；每个目标单独保存路径、动画和时间。Set size 保存宽高表达式及锚点。目标保留顺序和重复项；局部名称只对所属表达式生效。边界保留 AND / OR / 比较树以及两侧表达式，不降格为固定矩形。

Drag started、Dragged、Drag dropped 和四向 Swiped 可配置事件。每个重复器行保留独立身份；框架有独立运行状态。播放期间的坐标、尺寸、旋转和拖拽数据不写回工程。新模型严格校验字段、枚举、数量、递归深度和绑定标识；复制、组件同步、撤销与重开保留并重映射这些引用。

旧数字型 Move / Resize 仍按旧路径运行，不因加载而自动迁移。Add animation and expressions 是显式转换；缺目标或不支持尺寸动画的旧目标不能转换，原动作仍可编辑。尺寸动画按来源规则舍入尺寸变化。科学计数法不参与局部名称重命名；目标重排、删除或撤销后丢弃尚未提交的局部名称草稿，避免写到另一表达式。

## 运行语义与证据边界

普通目标的动画队列区分位置、尺寸、旋转通道与公开几何缓存，按最短剩余时长分段，保留已验证的事件顺序、提前缓存、重入与 Wait 分批。非等时组合可能出现原函数中的尺寸残差或缓存与绘制位置不同，未改写成理想插值。弧线按保留来源函数的定步采样对照。带阴影的部分偏心轨道端点受实际调度影响；不能把某次浏览器端点视作唯一精确值。

鼠标和触摸经过共享输入层；首个零位移也可开始拖拽，松开使用最后一次移动坐标。松开后的点击抑制与仍在进行的拖拽取消分别处理。页面跳转、删除已登记行、取消手势和关闭预览会清理活动输入及光标。离线导出的嵌套启动代码也显式传入相同输入处理器。

Widgets below / right 与 This repeater item 走专门消费者，保留已验证的兄弟筛选、尺寸变化方向、直接行尺寸更新及重排规则。原生 Layer、独立 PanelState 尺寸、fixed 元数据及部分跨父坐标路径尚未完整建模；内部复合容器的特殊压缩移动不冒充普通兄弟移动。非有限轨道与无进展的混合即时队列会原子拒绝，不复制来源中的病理循环。

表达式只开放有限、可验证的运算与控件属性，不执行任意 JavaScript。局部别名、This / Target、Window、拖拽值及数值格式化遵循已取证范围。原生编译器全部期望类型转换、作用域和生成节点路径仍有缺口。

来源证据分别见 [组合动画](runtime-transform-motion-evidence.md)、[真实 DOM 对照](runtime-transform-browser-evidence.md)、[拖拽](runtime-transform-drag-evidence.md)、[表达式](runtime-transform-expression-evidence.md)、[特殊目标](runtime-transform-special-evidence.md) 和 [核心实现](runtime-transform-core-implementation-summary.md)。这些记录明确区分原函数、真实浏览器与 DOM / 时钟替身；不代表原版编辑器或像素一致。

## 原生导入

严格读取器与映射器保留完整目标数组、局部绑定及边界树；只映射当前包内已导入、无歧义的身份。任一目标、未使用绑定、事件兄弟、条件或上下文无法解析时，整事件仍拒绝。

11 份不可变原生样本中新增 **6 个完整 Accordion Click 事件，18 个 Move 动作与 12 个已支持的兄弟动作**。移除这 6 项后，全部旧导入文档与前一发行基线完全相等；没有新增真实 Set Size 或带边界的完整事件，4 个滑块端点事件仍因目标缺失拒绝。合成测试验证结构，不代替真实文件恢复。见 [映射与回归](runtime-transform-mapper-evidence.md)。

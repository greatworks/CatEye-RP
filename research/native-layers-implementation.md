# Native Layer：结构、作者操作与共享运行时

本阶段已完成下述独立实现与程序验收。发行文件、源码绑定和最终归档哈希见 [验收记录](native-layers-verification.json)。完整 Axure RP 11 等价仍未达到。

## 本阶段范围

Layer 现在拥有自己的标识、有序成员和交互，可以嵌套，也可以作为动作目标。成员沿用所在页面、面板状态或中继器项目的坐标；组的位置不再叠加成另一个坐标原点。旧文档的平面 `groupId` 仍按旧模型读取。

作者端用 Ctrl+G 将同层选中元件建立为真正的组，Ctrl+Shift+G 解组。双击组进入成员编辑，Outline 可以选择嵌套成员；退出时返回实际所属容器。移动组会同步移动同一坐标范围内的成员，遇到面板和中继器等独立坐标容器停止改写内部坐标。复制、组件、撤销/重做、保存重开与字体收集均遍历成员结构。

组的保存边界由实际叶子元件计算，包含隐藏及未放置成员，考虑成员旋转，不重复施加内层组的旋转，也不加入阴影。空组为零尺寸。命名自适应视图中的位置修改保存到成员，组边界随有效成员几何重新计算。整组作者缩放、旋转和 pin 约束尚未完成，因此当前属性面板只开放组 X/Y，并显示只读 W/H。

预览、离线 HTML 和内部框架共用运行时。实现覆盖组的 Move、Resize、Rotate、组合动画、状态递归、悬停/按下传播边界及中继器行实例定位。组容器不通过 CSS 整体旋转子树；成员的轨迹、角度与组自身角度分别管理。首次 Base 视图使用生成数据边界，命名视图更新运行缓存，返回 Base 清除缓存并恢复声明几何。运行时边界与作者保存边界是两套已区分的规则。

## 原生导入

11 个原生样本中，10 个可导入文档新增恢复 182 个完整 Layer：Form 129、UI 40、Starter 12、Basics 1。新增的 13 个组 Click 交互包括 10 个选中状态动作与 3 个面板状态切换。另一个 Icons 样本保持原拒绝结果。去掉新增组包装后，10 个文档整体与阶段前基线逐项一致，包括元件、面板状态、样式、富文本、自适应声明及既有交互。

导入要求成员顺序、唯一归属、源页面/状态关系、已支持属性及事件依赖完整闭合。不支持的外层组仍可保留已支持的内部独立组与原有叶子对象；不会伪造“完整恢复”的外层组。原生中继器内部组、含不支持字段/动作的组和部分 fit 面板仍有缺口。最大紧凑语义载体为 28,926,107 字节，在现有 32 MiB 限制内。

完整来源、每个组和未恢复原因见 [导入审计](native-layers-format-import-audit.json)、[格式证据清单](native-layers-format-manifest.json)。

## 证据与验证边界

格式研究使用原始文件字节、元数据和静态 CIL，未执行原版 DLL。运行时证据先冻结了 78 项原始 JavaScript 精确函数探针；这些探针使用显式宿主替身，不能代表原版完整浏览器、编辑器或画面一致。后续独立反例审查分别保留组缩放、初始状态和组合偏移的失败与修正证据，详见 [运行时证据](native-layers-runtime-evidence.md)。

修复后的源码已通过 4,470 项单元测试（167 个文件）、801 项读取测试和类型检查。独立审查包括 111 项原始函数探针、50 项运行时对照、13 项原始事件引用核对，以及 9 项作者/模型检查。组内富文本遗漏自适应字号/颜色的问题已修复：仅对显示副本投影显式格式，拖动及保存仍使用源内容；新的生产浏览器专项验证了进入/退出嵌套组、颜色单项覆盖、面板/中继器、单次行文字展开、拖动/撤销和预览。

第二候选桌面包通过真实 IPC 打开、保存、重开、组移动、预览/离线动画、状态传播及内部框架检查。四份原生工程的完整保存模型与冻结的导入审计逐项一致；7 张实际截图已检查。最终生产浏览器为 324/324 通过，没有跳过或不稳定重试；同一个 ASAR 的 12 组桌面检查全部通过。旧测试产物由验证脚本恢复原字节，本轮产物单独保留；最终 ZIP 逐文件核验写入验收记录。

首次全量单元回归、运行时独立红测和富文本独立红测均保留。第一轮生产浏览器为 319/323 通过，4 项失败来自旧退出按钮/层级预期和原生对象顶层查找假设；测试改为实际容器退出及递归查找，原有保存、几何和字体断言仍保留。富文本专项首次发现测试行数据缺少列声明，随后两次开发服务器加载超时，均未计为行为通过；相同最终用例在静态生产构建中通过。旧交互样式桌面脚本保留原文件，本轮副本按冻结导入审计更新顶层统计和 Layer 递归查找，继续验证原生真实悬停及精确样式。三个中间运行时源码版本仅留有历史哈希、没有完整旧字节，这一证据限制明确保留。详细记录见 [独立运行时审查](native-layers-runtime-integration-review.md)、[作者审查](native-layers-authoring-review.md) 和 [富文本修复记录](native-layers-authoring-rich-correction.md)。

创建组时将组放在所选元件最高绘制位置、作者范围退出、控件布局等属于独立编辑器约定，尚未通过原版 GUI 对照。原生 Layer 的完整放置/contained/master 规则、作者缩放及 pin、完整表达式、复杂复合容器、`.rp` 写回、云协作和逐像素一致仍未完成。原版专有代码与资源不进入发行包；独立许可的 Roboto/Open Sans 字体保留第三方声明。`fullAxureParity` 保持 `false`。

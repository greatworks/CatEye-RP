The browser executes exact retained JavaScript with declared fixtures; managed evidence is read as ECMA-335 records or interpreted records, never loaded as vendor code. This is not an original GUI or complete exported-project comparison.

## Implementable contract

1. Keep a source SVG asset identity separate from the current full style. `_applyImageAndTextJson` (style.js1647–1714) passes ordinary controls to `_applySvg`; only ImageBox takes its state URL branch. `_applySvg`991–1645 reuses the inline SVG root and its paths, and reuses or creates one inner style node. Every application rebuilds that style text. For the tested solid controls, state/adaptive/action/P94 changes preserve path d, viewBox and SVG width/height attributes.
2. Keep immutable initial presentation colors and geometry, plus mutable stroke-width attributes. Truthy nonzero borderWidth writes each stroke path's attribute. Zero skips that write; it retains the latest width of this asset. Rebuilding CSS, clearing applied-action records, switching state, changing P94, or applying adaptive styles does not reset it. The checkbox's runtime mark CSS width still uses the root generated object's `buttonSize`, not the full override's `buttonSize`. The initial radio mark is fill-only; runtime solid borderFill also supplies generic stroke CSS.
3. Resolve a full style before painting: document default → object's named normal style → object.style → current panel style → computed adaptive/state overrides; then shallow-overlay accumulated action styles. Omitted state fill/borderFill/borderWidth inherits the lower full style. Explicit null replaces it; null fill/borderFill makes fresh runtime CSS omit that color, exposing the immutable initial presentation attribute. Do not pass an isolated sparse state patch directly to the SVG consumer and confuse omission with null.
4. Adaptive normal styles merge oldest → leaf, including each named base style. State lookup searches leaf → ancestor and takes the first state's complete named+local patch. A present truthy `stateStyles` map with no matching state returns an empty patch and stops inheritance. Thus `stateStyles={}` blocks ancestor state effects while `stateStyles=null` permits searching further. State priority is normal, mouseOver, mouseDown, focused, selected, error, hint, disabled. Merge is shallow: a fill object replaces its carrier, not individual nested fields.
5. Action styles accumulate sparse declarations with `$.extend({}, previous, next)`. clearPrevious removes old classes and the action record; it does not remove SVG paint/width attributes. The subsequent full normal width0 can therefore still show the previous nonzero width. Clearing only the record performs no paint.
6. For ordinary noncontained adaptive objects, adaptive.js271–317 calls setAdaptiveStyle; style.js2377–2417 repaints if id_img is an SVG, then uses CSS scale for non-Rectangle size overrides. It does not create a new selection SVG. doc.js601–611's image lookup only matches img; its SVG URL lookup only matches object. Neither matches inline SVG. The tested call to applyImage found neither and preserved the inline asset.
7. A new DOM asset starts with its own initial presentation attributes. The fixture replacement witness proves this DOM fact, not a native event trigger. Native repeater.js174–207 uses existing pre-generated items; the alternative209–283 removes items and constructs fresh contents from the template script via clone/html. Width history resets on that actual reconstruction, not merely on a refresh label. Full refreshType/persist/preEval caller eligibility belongs to the dispatch investigation.

## Initial generated state versus runtime initialization

New retained-CIL pNPt projection: **8/8** (two control types × authored Selected/Disabled false/true), in `selection-state-assets-initial-probes.json`.

- JSON writer jJeK **100694305** reads Disabled **100695304** at IL521 and emits key disabled / true at IL565/570 only if true. Selected **100695308** is read at IL618 and emits key selected / true at IL662/667 only if true. Decoded literals and full source records are frozen.
- HTML writer pNPt **100699649** captures authored Disabled into local2 and Selected into local3 before invoking zNUD(false,false) at IL129–138. Owner class helper wNxE **100699330** receives those saved booleans; arg3 selects the decoded selected class at IL764–793, and arg2 selects disabled at IL65/222–251.
- JNCt **100699500** receives saved Selected as arg10 (call IL856–860); arg10 gates the checked attribute (IL845→700–734). Its disabled arg7 is explicitly zero in this call; later runtime initialization handles the disabled control. This is separate from the owner disabled class.
- zNUD **100702045**, named TrapSelectedAndDisabled by its retained closure, saves prior fields, sets MNUM trapping=true, then writes Disabled=false and Selected=false. The new eight cases all capture the normal aNP5 call with state0, selected=false, disabled=false, trapping=true.
- Prior retained aNP5 **100699650** replay, `selection-layout-indicator-asset-probes.json`, proves state0 temporarily sets Selected=true while invoking its renderer, then restores the prior value after success. That puts the mark into the normal asset even for an unchecked control; page CSS hides .btn_check unless an ancestor has selected.
- SelectionButton.TIdc **100702041** gets its effective provider before drawing the outline/fill and captures BorderFill (IL1641–1653) before checking Selected (IL1796–1802). The later nJpj(0/8) scopes read/compare the text-related value l5Bl to decide whether/how to draw the mark; they do not replace the already captured mark BorderFill. Checkbox/Radio SIll pass that captured fill to their respective marker generators.
- Consequently the ordinary source asset belongs to the normal generation path, with authored selected/disabled metadata kept separately for initial DOM classes and runtime initialization. It must not be synthesized by blindly merging authored Selected/Disabled style patches into the source asset. The full cache/provider/theme/graphics lifecycle was not executed here; exact initial native paint is bounded by the earlier retained solid fill and glyph evidence. Any generated external-image, compound, master, complex shadow, or unsupported paint variant remains outside this result.

The independent dispatch agent owns when initialization actually invokes the painter. In particular, a mark's presence in initial SVG and an HTML checked=true value are not proof that runtime selected paint has run.

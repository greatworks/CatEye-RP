# Selection input design correction

This note supersedes two premature constraints in the initial `selection-input-model-analysis.md`. That initial report and its hash record are retained as a design hypothesis, not implemented or native-proven behavior. No product files have been changed at this point.

1. **Queue raw input, then plan sequentially.** The first draft required input projection before queueing. That was too restrictive before xFY0's geometry lifetime was proved. The agreed host queues each frame's raw same-diagram displacement and modifier snapshot. During ordered `session.plan`, the new input model runs first using the captured original/settings and any source-required current controller geometry; its processed delta then reaches the existing layout planner. Font-pending frames therefore see the correct preceding accepted state. Processed deltas are never fed back to the input model.
2. **Controller mode, not a broad Ctrl rejection.** New source shows UbNP checks the masked modifier set for exact Control, rather than merely testing that the Control bit is present. Ctrl+Shift/Alt may still initialize resize mode. The source-initialized mode should be captured separately. A rotation-mode branch can remain explicitly unsupported in this ordinary unrotated resize adapter; it must not be used to reject every Ctrl-containing combination. Within a confirmed resize mode, supported keys must follow the actual input/snap/downstream rules rather than trigger an invented rollback. Single Selection rotation capability and mode lifetime remain under source investigation.

The concrete NIoi override returns Alt and its platform factory binding is now reported closed by the evidence owner. It supplies the snap-bypass predicate; Shift remains independently available to candidate/aspect calculation. Raw key masks remain in the trace. Final modifier output and any numerical-planner guard change will be coordinated only after the full admitted resize-mode path is established.

The proposed API therefore needs an explicit captured controller/input snapshot and a current frame, not only a pre-snapped displacement. Exact candidate geometry fields and grid parameters still await the independent source interpreter. Guides/object search, key-only delivery and general rotated input remain separate gaps.

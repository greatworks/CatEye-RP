# 独立原生圆角：实现与验收边界

本阶段补齐原生 P71 CornerRadius 与 P81 CornerVisibility 的独立行为，不表示 Axure RP 11 完整重建已完成。完整目标仍包括原生双向文件互通、其他形状/组件、协作发布及原版 GUI/像素差分。

## 原版证据与实现

11 个原始 DesignDocument 默认样式都明确存有 P71=0、P81=15。P81 的位 1/2/4/8 对应左上/右上/右下/左下，与边框位序不同。原生成器 CSS、动态 JS、作者属性写入和存储载体分开取证：281 个原 JS 受控探针与 512 个受限 CIL 前缀重放均通过。未执行原版 DLL 内部方法；受控重放不是原版 GUI 观测。详见 `native-corners-evidence.md` 和 `native-corners-format-evidence.md`。

模型新增可选 `cornerVisibility` 四布尔元组，严格校验完整长度与布尔值；缺省解释为全角。该字段可用于普通样式、共享样式、七种状态、SetStyle 及自适应声明。P71 编辑不清除 P81，P81 编辑不改变半径。原 `cornerRadii` 任意四值继续作为兼容扩展保存；显式统一半径沿用旧行为退出独立四值模式，角开关自身不丢弃这些数值。

CornerEditor 提供 Radius 和四角开关；状态与动作分别有 Override 入口。多选命令针对每个目标自己的样式/状态求值，只改请求的属性，不复制当前选中项的其他角或颜色。实际同值目标不改本地声明；Affect all views 仅清除发生变化的原生键，包含非活动视图。已声明参数的矢量矩形点击默认角开关时显式保留 all-true 元组，防止退回旧快照模式。

普通 HTML 使用原 CSS 的角开关与相邻边框相等规则，半径由浏览器缩放。参数化 SVG 矩形按原动态 JS 规则计算独立描边与填充：单角、对角允许大于短边一半，填充可在相邻两边均隐藏时保留圆角。画布、预览、内部框架和离线导出使用相同工厂。渐变描边遵守同一角掩码。

矩形资格检查验证完整控制点顺序、0.44 三次柄和相邻角尺寸约束；以归一化路径判定，当前宽高变化不取消资格。任意节点或柄离开严格矩形族时保留实际路径。缺少显式原生参数的旧矢量快照不自动转成参数矩形，也不开放新角控件；它们继续可用节点编辑器。这避免把旧路径误用默认半径改平。

## 原生恢复

独立参数只从确定且有效的原生 P71/P81 恢复，保留每个属性的来源；不再以路径四值的最大值冒充原始 P71。基态缺少完整参数时保留路径快照与诊断，状态或局部声明不能反过来猜造基态。状态/局部 P71/P81 分别恢复显式字段，0、全关、全开均保留，未知值与错误投影拒绝。

11 个原始样本的成功/拒绝边界不变，无新增或丢失元件；1,256 个导入元件有独立参数，52 个部分角掩码，460 个正半径。Sample form patterns 中新增恢复 6 个 Click→SetSelected(true) 事件。两个初始选中元件的非圆角绘制值在新 Base+Selected 组合下保持；其旧路径圆角快照被纠正为原生 Selected 的全角5，不能描述为全部外观不变。

仍未扩展 28 个合并端点的 pill 路径识别。原生读取器沿用已证严格路径域；产品矩形族识别更宽，不代表这些原生载体已经自动准入。合成局部自适应正例与真实样本分开报告，真实样本没有局部 P71/P81 见证。

## 检查、修正与证据

完整最终计数及文件哈希见 `native-corners-verification.json`。专项浏览器覆盖全部16角掩码、实际像素采样、普通/全视图异值多选、撤销重做、保存重开、状态与动作、行隔离和内部框架。实际 Windows 包另检查原生文件对话框、离线导出、历史线型、原生 .rp 导入、框架与 All Views 回归。

最终完整检查为 3,395 项单元测试、657 项读取器测试和 271 项生产浏览器测试；另有23项专项浏览器、5组同一 ASAR 的实际 Windows 脚本、7次本阶段桌面工程保存比对、1个离线导出及3张已查看截图。一次大样本单测在并发验证时超过5秒，保留记录后以2 workers独立重跑完整套件通过，没有放宽断言或超时。隐藏 Electron 窗口的 Playwright 元素截图稳定性等待也超时；测试适配为 capturePage 区域像素读取后通过，产品与 ASAR 未改。

真实失败记录予以保留：最初模型/渲染红测；独立审查发现合法大单角路径被旧半边上限拒绝；完整套件中原先把 P71/P81 当不支持字段的旧断言。大单角问题已以相邻角约束修复，原初工具失败未采集瞬间源码哈希，报告明确保留这个限制；随后最终独立复核43项通过。测试夹具另修正了探针名称、共享可变路径和 inlineFrame 空标题，未把这些测试自身问题算作产品修复。

## 尚未完成

- 原版初始 managed 填充会独立夹取某些极端大半径；动态 SVG 会复用描边夹取结果。当前参数矩形渲染覆盖后者，没有证明初始原版像素等价。
- 原动态 setBorder 在零描边/无线型时可跳过重建旧路径；产品按当前声明重绘，未复制该旧路径缓存行为。
- 无完整参数的旧矢量快照与上述未识别原生路径保留原范围。
- 原版 Untitled 菜单可读取，截图仍返回 FrameArrived timeout；没有原版画布操作或逐像素验收。
- 完整 `.rp` 写回、其他形状/组件、自适应专用传播与协作发布仍有缺口。

旧发行包与上一阶段源码/验收均保留在 `.build/before-native-corners/`；候选通过后才提升到 `release/`。历史 artifacts 在回归过程中逐字节恢复，新的运行产物单独留存。

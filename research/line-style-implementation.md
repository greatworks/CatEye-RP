# 线条样式阶段

本阶段接入九种线条图案、含 None 的二十九种端点样式及矩形四边显隐。实现根据固定的 RP 11.0.0.4150 分发包中的静态代码和原始运行时函数实验推进。原版 GUI 与逐像素对照尚未完成。

## 编辑与数据

Line pattern、整对 Line ends、四项 Border visibility 分别保存，颜色、渐变和线宽仍是独立通道。缺省值为 Solid、None/None 和四边可见；显式设置这些值会覆盖继承，取消覆盖才恢复继承。作者面板、工具栏、状态、Set style、自适应视图及组件使用同一数据约定。混选会逐个按几何能力过滤样式，避免把箭头写进输入框。

图案的枚举顺序及虚线数组来自原生 LineStyle 与笔对象。JSON 保留笔单位数组，原版运行时和 SVG 写入器再乘线宽。原生编辑笔的 Round DashCap 与导出 SVG 是不同证据链，不据此声称导出线帽为圆形。

填充轮廓与描边路径分别绘制，端点使用独立几何。渐变仍以元件坐标为基准；端点的平移和旋转须抵消对应的渐变变换，避免右侧红色箭头错误采到左侧蓝色。静态坐标实验覆盖 24 个非零位置与方向组合，预览和离线导出另有实际像素检查。

## 导入边界

PName 16 为线条图案，PName 17 为完整的起点/终点对。原生边侧位置的位标记为 Left=1、Top=2、Right=4、Bottom=8；工程按 Top/Right/Bottom/Left 保存。

已有十一份样本中，当前导入恢复两条 Default 库箭头线。另六条箭头路径仍因旋转几何未确定而拒绝，一条连接线仍缺少可恢复几何。不能把解析器发现的九个箭头对象都计为成功导入。

同一组样本恢复 1,731 个实线图案值和 67 个部分可见边框：31 个矩形、28 个输入框、8 个下拉框。元件、嵌套元件、事件及动作数量均未新增；最大的紧凑导入报告为 28,689,168 字节，低于现有 32 MiB 边界。图片、树标签与未通过矩形识别的任意路径继续采用既有保守导入范围。

## 当前限制

- 动态端点根据当前宽度和样式重新生成。原版 style.js 对初始箭头路径施加线宽差的缓存残留行为不属于本阶段等价范围。
- 四种 crow 分支采用已证实的原始中心曲线与平头描边；完整原生曲线扩边算法尚未逐像素复现。
- 矩形边侧重建须通过轮廓检查；任意矢量路径不能据控件名称直接改为矩形。图片的边框规则单独处理。
- 全部旋转、原生连接线、复杂线帽/连接及完整 Axure 功能一致性仍未完成。

## 验证状态

最终完整回归通过：单元测试 2,356/2,356（105 个文件）、文件解析 477/477、生产构建浏览器 208/208、同一 Windows 程序包 24/24 个冒烟脚本。浏览器无失败、跳过或重试通过项；预览和离线两条线条运行时流程均包含渐变端点像素检查。构建同时通过 TypeScript 检查。

桌面专项覆盖保存重开、作者面板、图案和全部端点、边侧显隐、预览、离线导出、内嵌播放器，以及真实 Default.rplib 的 Worker 导入与两条箭头实际绘制。历史演示与桌面报告在回归前保留原字节，本阶段生成的替代截图及导出文件另存，避免覆盖此前证据。交付包哈希、压缩包与测试程序一致性及证据文件校验以 [最终验证记录](line-style-verification.json) 为准。

## 修复与回归记录

定向测试曾发现混选时输入框被后续文字样式合并重新写入端点；两条更新路径现共用几何过滤。独立复核另修正了空封闭轮廓影响前一开放轮廓、原生圆角路径被重建为方角、隐藏边漏绘、斜杠端点顶点顺序及渐变端点坐标问题。

首轮完整浏览器回归为 197/208，11 项失败均来自旧测试仍假定填充和描边共用一条 SVG 路径。已按填充、描边的语义分别定位，保留原有几何、颜色、线宽断言；该 11 项定向复跑全部通过。原失败报告保留为 `.build/line-style-e2e-first-full.json`，定位调整及文件哈希见 [回归定位记录](line-style-semantic-locator-evidence.json)。桌面专项首次还发现测试把 SVG 属性序列顺序误当成语义；现按属性名和值比较，保留全部值与几何检查。

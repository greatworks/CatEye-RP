# 中心旋转与编辑几何阶段

本阶段以 RP 11.0.0.4150 的静态托管代码、27 项原始运行时函数探针和 11 份固定样本为依据。新增受限中心旋转导入，修复本应用旋转缩放与框选。原版 GUI 当前仍受已记录的 Computer Use 几何和截图故障阻碍；原函数实验与本应用浏览器测试不能替代原版操作或像素对照。

## 导入契约

仅恢复已识别的存储 VectorShape 路径、已明确为空的文字、明确 determined/overridden 的本地 P50、完整样式缓存链及文档默认的单位变换和中心原点。实际位置和尺寸保持未旋转布局矩形，角度为屏幕坐标中的顺时针度数；不取整，不把旋转后包围盒再当作布局矩形。

P1401 是五个字段的原生变换对象，不能当作六系数矩阵。其通用 CSS 组合顺序及任意原点的单位尚未证实；显式/匹配样式变换、非中心原点和不完整协议继续拒绝。文档默认缓存中的 Rotate=0 不覆盖明确的本地 P50。独立文字旋转和旋转状态覆盖未扩展。

11 份样本新增 12 个顶层元件，嵌套元件、事件与动作数量均不变：表单库 4、UI 库 2、Prototype Starter 1、Quick Win 2、UX Prototyping 3。其中六条箭头线保留 `89.13596303062127°`，六个小箭头为 `180°`。新增元件的位置、尺寸和路径均逐项匹配原始清点；去除这 12 个明确新增对象后，完整工程与不可覆盖的阶段前快照精确相同。UI 库中复杂/虚拟交互仍整组拒绝。最大紧凑报告 28,724,053 字节，保持在现有 32 MiB 边界内。见 [完整导入审计](rotation-import-audit.json)。

fit 面板用可见子元件的旋转包围盒右/下边界计算尺寸，与现有运行时计算方式一致。负向扩展不会隐式平移原点，隐藏子元件排除；嵌套 fit 和未恢复依赖的原子拒绝由定向测试覆盖。

## 编辑与演示

Style → Layout → Rotate 设置角度；缩放时先将指针位移转换到控件局部轴，再按最终尺寸固定对侧边或角。只有拖动轴使用现有最小尺寸与整数取整；另一轴的小尺寸和小数完整保留。框选采用旋转矩形相交，避免斜向包围盒空角误选。原版编辑器的精确手势策略尚未核实。

[演示工程](../artifacts/rotation-demo.rea.json) 包含正负角度、渐变虚线端点、三次曲线、可输入的旋转表单、可点击的倾斜按钮、父子旋转和内联页面。对应 [离线 HTML](../artifacts/rotation-demo.html) 可断网运行。演示使用本项目独立编写的内容与样式。

## 缺陷与验证记录

两个真实浏览器用例先复现了 90° 控件沿错误屏幕轴缩放，以及框选命中未旋转布局框的问题。随后 12 个定向失败用例复现了单轴拖动把原生 6/7 像素高度改为 8、或把未拖动的 `73.99934480684509` 宽度改为 74。修复后 67 项几何测试及定向浏览器检查通过。原失败日志均保留，见 [作者端审计](rotation-authoring-audit.md)。

最终完整单元、解析器、生产浏览器及同一 Windows 程序包验证结果以 [本阶段验证记录](rotation-verification.json) 为准。打包专项逐一核对 5 份原生样本的 12 个旋转元件，覆盖 Worker 导入、保存重开、实际 DOM 变换与边界；演示还覆盖预览、内联播放器与断网导出。历史报告和演示保留原字节，新回归产物另存。

首轮完整单元为 2,454/2,459；五个旧断言仍使用旋转导入前的样本数量。完整工程审计确认差异仅为明确新增的旋转元件后，更新对应计数并增加原角度核对，保留图片字节、路径、交互、旧元件和保存回读断言。完整复跑 2,459/2,459 通过；原失败报告保留为 `.build/rotation-unit-first-full.json`。文件解析 496/496 通过。

生产构建的真实 Edge 浏览器回归 210/210 通过，无失败、跳过或重试通过项。截图复核覆盖编辑器、预览、嵌套父子、离线页面和原生箭头导入，记录见 `.build/rotation-visual-review.json`。

同一 Windows 程序包的 25/25 个桌面脚本全部通过，覆盖旋转专项及既有线条、渐变、阴影、框架、树、菜单、表格、矢量、文件导入、页面树、交互样式、表单和文字/链接流程。回归产生的新截图、导出和桌面报告另存于 `.build/rotation-regression-artifacts-*`；历史原件已逐项恢复并校验。

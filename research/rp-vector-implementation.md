# 存储矢量路径实现与验证边界

2026-10-13。本轮将原生存储控制点转换为可编辑的矢量路径，替换导入椭圆的 CSS 近似轮廓。行为来源为 [CIL 证据](rp-vector-path-evidence.md)，实际文件结构为 [11 样本清点](rp-vector-census.md)。原版 GUI 截图仍受 Computer Use 桥接超时阻碍，没有宣称完成原版界面对照。

## 数据与绘制

`vectorPath` 保存有限数值组成的 M/L/C/Z 命令和填充规则。坐标以元件宽高归一化保存，允许越界控制柄；路径尺寸变化不改写节点。文档解析限定最多 4096 条命令、坐标绝对值不超过 10000，拒绝任意 SVG 字符串、未知命令/字段及非有限值。仅 box、ellipse、path 类型可携带该字段，path 类型必须有路径。旧矩形/椭圆未迁移。

React 编辑器、预览和导出 HTML 使用同一个无模块依赖的 `vectorPathData` 函数生成 SVG。文字单独叠加并裁切，SVG 允许描边超出外框；选中样式、动态移动/缩放、面板与中继器行状态保持原运行时规则。导出前仍执行完整文档验证，脚本使用现有 JSON 转义。用户可在 Libraries → Path 新建路径，在 Style → Vector path 选节点、修改端点及控制柄、增删节点/子路径和闭合轮廓。当前没有画布拖点、布尔运算、弧或二次曲线命令；交互命中仍使用元件矩形。

## 原生恢复

严格校验四字段控制点记录。相邻锚点使用前一点 HigherHandle、后一点 LowerHandle；两柄缺失时保留直线，只缺一柄时以其锚点补齐三次控制柄。最后的 HigherSegmentExists 决定闭合描边；开放轮廓仍参加隐式闭合填充。普通原生 SVG 绘制链已明确指定 nonzero。复合轮廓保持顺序与方向。

含内部断段的轮廓需要不同的填充和描边路径，本轮整对象拒绝；两个原生分支对单轴 NaN 行为不一致，本轮亦拒绝。最多 256 轮廓/3500 顶点，再校验转换后 4096 命令限制。RP11 缺失空富文本推断沿共同 VectorShape 序列化链扩展至已知形状枚举，但保留严格版本和字段白名单；旧 9.0 包及未知 SmartControlPoints 等字段不作空文本推断。

非自定义 Vector 的原版轮廓会按 Shape、尺寸、样式重新生成；本实现恢复保存时的轮廓快照，未复现最终描边位移、端帽/箭头、像素对齐、渐变与字体自动尺寸。既有自适应、容器、变换和事件原子拒绝门槛仍然保留。例如 Flow 的 Delay 已恢复其单柄曲线，但因 6 个未解自适应样式仍拒绝导入。

10 个可导入样本（含元件库）新增 281 个元件，原先 1360 个已导入元件的既有字段全部比较一致；唯独新增 `vectorPath`，面板新增子内容单独计数。六个 `.rp` 样本总计从 432 增至 482，已遍历跳过数从 144 降至 94；未关联状态另计。Icons 元件库仍超过 200 页上限。

## 修复与验证

独立审查发现混合选择路径与输入框时，节点编辑会将路径字段写入全部选择对象。使用修复前生产构建运行新增浏览器回归，实际复现输入框消失；已将路径修改限定为当前元件，普通多选样式/几何编辑保留。回归检查当前路径改变、另一路径和输入框原对象完全不变、保存重开及预览输入仍正常。

最终测试、样本来源摘要、Windows 包和 ZIP 校验结果见 [本轮验证记录](rp-vector-verification.json) 与 [发布验证](../release/verification.json)。这些测试验证本应用与受限存储语义，不替代原版 GUI、完整 `.rp` 写回或逐像素等价测试。

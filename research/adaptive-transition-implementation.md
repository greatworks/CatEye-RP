# 自适应视图运行时切换

2026-10-15。本阶段修复加载时机和视图切换状态；原生 Axure GUI 的画布行为仍未验证。

## 行为变化

- 核心运行器在首次 Loaded、Item Loaded 和导航后的加载动作之前选择视图。隐藏元件和非活动面板不再依赖先绘制一次才能读取正确尺寸。
- 只在实际视图变化时恢复声明的几何、显隐和样式；同视图内调整宽度保留动作结果。显隐恢复不走普通 Show/Hide 动作派发。
- 清除动作样式时保留普通元件的运行时文字，恢复文字原始格式来源，再叠加目标视图和当前状态；不把动作写入的完整样式当作声明。
- 中继器区分普通数据刷新和自适应重建：后者重建模板内容、恢复初始分页，保留源数据、查询、标记和对应行的选中/错误/禁用状态。提示显示管理器与提示样式标记分开处理。
- 预览、离线根页面和嵌套框架均向核心提供宽度策略；框架读取自己的窗口宽度。作者工程不因运行而改变。

## 实现边界

`createOfflineRuntime` 第五参数接受 `{width?, clampToPage?}`。显式 `{}` 使用当前页面保存的宽度；省略参数保留旧的外部自适应输入契约。`setViewport` 在入队前复制并验证策略，`adaptiveViewId` 提供当前视图。导航对新页面重新计算宽度和断点，不能沿用旧页已裁切的数值。

显隐排除单元格、子菜单及菜单内部表格；几何重置按不同阶段处理。通用原生 `isContained` 没有完整模型映射；树标签的联带几何清理仍以本产品的直接子节点结构为边界。嵌套中继器保留完整行身份是本产品模型的递归扩展，不等于原版嵌套数据语义已全部验证。

未增加原生自适应继承链、独立的未放置/limbo 状态或 Adaptive View Changed 作者事件。当前断点规则仍为覆盖宽度的最小 max-width。保留同 DOM 的渐变色标缓存规则。原版回 Base 时部分 SVG 最后 paint 参数残留与普通文字缓存恢复是两条不同路径，不能据文字测试宣称所有 SVG 像素等价。

## 失败回滚修复

收尾审查发现：自适应重建的 ItemLoaded 导航到新页后，如果新页 Loaded 抛错，旧实现恢复了页面数据却未恢复导航提交标记；下一次无关动作会重复加载原页。预览与 file 离线页面各有一个有效红测，见 [故障记录](../.build/adaptive-rollback-red-evidence.json)。

现在导航 epoch、提交标记、Case menu 数据及发布状态随事务一起回滚。旧 Wait 的取消延迟到最外层同步事务成功，新事务创建的 Wait 在失败时撤销；成功导航仍取消旧页等待并保留目标页等待。菜单 ID 保持单调，避免旧按钮引用重试生成的新菜单。12 项新增核心用例分别验证模块与序列化运行器。这是本产品的错误恢复约定，不能据此推断原版 Axure 的异常处理；普通 navigate 的整个 Loaded 流程没有扩成新的整体事务。

## 证据与检查

期望值来自已固定的 Axure RP 11 运行资源，见 [显隐与事件依据](adaptive-style-reset-events-evidence.md)、[原函数转换探针](adaptive-transition-probe.json) 和 [真实浏览器 DOM 文字缓存探针](adaptive-transition-text-probe.json)。探针使用明确的模拟依赖或合成样例，未运行完整原版生成工程。

旧已验证发行构建已复现 8 项对应浏览器差异；失败记录与测试样例错误修正分别保留在 [基线记录](../.build/adaptive-transition-baseline-evidence.json)。本轮已通过 2,739 项单元测试（117 个文件）、236 项完整生产浏览器回归、15 项定向浏览器检查及类型检查。新桌面候选包完成 5 份工程的预览、file 离线页面、20 次保存回读核对，并记录 25 张截图；其中 8 张已人工查看（原先查看的 6 张在修复后重新捕获，逐字节一致）。原型运行未修改作者工程，未记录网络请求或运行错误。最终发行字节、受影响功能回归及证据哈希以 [验收记录](adaptive-transition-verification.json) 为准。

用户确认进入空白编辑器后，本轮重新检查并打开了已授权的 Axure。文本树可见 Untitled 和菜单，但截图、控件缓存与窗口激活仍失败，详见 [原生窗口复查](axure-runtime-recheck-2026-10-15.json)。没有据此声称创建或导出原生测试工程。

# 全视图作者编辑：实现与验证

本阶段在独立编辑器中接通 **Affect all views**。原始依据为 Axure RP 11.0.0.4150 的静态 CIL、属性载体和受控重放；没有把原版 DLL 运行或 GUI 观察当作本轮证据。项目仍为 0.1.0 开发版，完整 Axure 一致性尚未完成。

## 用户可见行为

- 开启后，普通位置、尺寸和外观编辑与当前有效值比较，将真正变化的属性写入 Base，并清除所有本地视图中该属性的覆盖。其他属性、对象和页面保持原值；非活动视图也只清除对应属性。
- X/Y 是一个完整位置，W/H 是一个完整尺寸；填充和边框各是完整的纯色/渐变通道。相同值不会抹掉其他视图声明。拖动返回原点、取消、撤销和重做恢复完整工程状态。
- 文字内边距四边独立。编辑右边距不清除另外三边；后续 Base 右边距改动仍可被各视图继承。保存兼容旧四边数组，新局部声明使用稀疏 `textPaddingSides`。编辑器与播放器只得到合成后的完整数组。
- 当前存在任意状态效果对象时，编辑效果按完整状态图写入 Base、清除所有视图的状态图覆盖。当前完全没有效果时，首次添加只写当前视图；空的单个状态对象仍算已有效果。这一特殊分支来自原版静态代码。
- 富文本整控件格式命令可以重置混合段落/文字片段；已经一致的重复命令保持真正无改动。运行时预览与离线 HTML 不改保存工程。
- 既有放置、新增与删除范围沿用同一开关；Use inherited effects 仍是明确的当前视图恢复操作。

## 实现位置与证据

模型、作者界面、历史事务和严格校验见 [作者端实现](adaptive-all-views-authoring-implementation.md) 与 [哈希清单](adaptive-all-views-authoring-implementation.json)。播放器在 `src/runtime/export-runtime.ts` 中按祖先到子视图合成四边声明，并去除仅用于存储的稀疏元数据；序列化到离线页面的运行时使用同一逻辑。

[普通属性证据](adaptive-all-views-authoring-evidence.md) 包括 14 项受限 CIL 重放和 17 项属性载体断言；[效果证据](adaptive-all-views-effects-evidence.md) 包括 17 项受限 CIL 重放。重放使用明确的依赖替身和写入接收器，不等同于执行原版应用。研究报告、原 DLL 与相关静态材料均有哈希绑定。

## 验证与历史保留

新测试覆盖模型 49 项、单边作者命令 15 项、模块/离线序列化运行时 16 项，以及真实浏览器操作 10 项。全套、浏览器和实际 Windows 包的最终结果由 [本阶段验收](adaptive-all-views-verification.json) 记录，不能从单元测试推断原版 UI 一致性。

初始模型、运行时及两项浏览器失败记录保留在 `.build/adaptive-all-views-*red*`。第一次完整单元运行的 1 处失败来自旧测试要求局部内边距仍保存成完整数组；现同时检查稀疏四边声明、保存重开后的完整有效值和 Base 不变，原失败报告保留。没有弱化行为断言。

独立审查还发现异值多选时，单边内边距命令误带上第一个控件的另外三边。真实浏览器在当前/所有视图两种模式都复现该问题。修复使用暂态的单边命令，逐目标计算自己的四边数组；已经同值的目标不物化默认值，也不清除其他视图。首次候选构建、原失败报告、测试及后续修复记录分别保留；原来的单控件用例保持不变。

桌面验证通过实际候选 EXE 操作工程打开/保存、撤销/重做、预览和离线导出，保存结果完整比较；6 张截图分别覆盖填充与内边距的作者界面、预览和离线页面。[演示工程](../artifacts/adaptive-all-views-demo.rea.json) 与 [离线示例](../artifacts/adaptive-all-views-padding.html) 由本产品生成，并非 Axure 原生文件。

发布前逐项比对构建输入、ASAR 内容、22 个开源字体及其许可证、ZIP 所有文件。此前发布包和 107 份验收证据保留；旧套件重写的截图/导出先另存，再恢复旧证据字节。本轮没有修改原生读取器，之前的 633 项读取器结果与 11 个原始样本回归仅在相关源码和证据字节不变时复用，并明确标注为之前的验证。

## 剩余差距

- 原版 GUI、原版画布交互与逐像素对照未完成。
- 原生 Layer/master、contained owner、临时 provider 和命名样式专用传播未补齐。
- 任意四角半径和四边线宽是既有产品扩展，不等同于原生统一值加可见性掩码。
- 完整原生 `.rp/.rplib` 导入、原生写回及其他尚未实现的 Axure 功能仍有缺口。

本阶段没有新增依赖，没有打包 Axure 专有代码或资产。仅保留此前已核实的 Apache-2.0 Roboto/Open Sans 字体与完整许可证。

# Current parameter geometry and custom point editing

本阶段修复：参数矩形缩放或改变半径后，画布已经显示新轮廓，但数值节点编辑器和画布锚点仍使用导入时的旧路径。实际源样本的 200×6 胶囊形改为 240×60、半径 18 后，旧首点位于 (0,30)，新编辑首点应为 (0,18)。

## 原始证据与推论边界

- `native-point-editing-evidence.md/.json`：非 Shape300 的 LN4g(0) 用当前 SizingRect 和参数生成编辑点；自定义 Shape300 直接取存储点。384 组有界 CIL 几何回放覆盖全部角开关、圆形、胶囊形、极小及超大半径；21 组控制流程回放核对身份转换与快照恢复。
- `native-point-editing-format-evidence.md/.json`：真实自带库中有保持矩形外观的 Shape300，也有仍保存 P71 半径的自定义形状。几何外观或半径字段都不能代替持久身份。
- 原版窗口 Untitled 可通过可访问性接口读取，截图仍返回 `FrameArrived timed out`。没有原版画布交互或像素一致性验证，也没有执行原版 DLL 内部方法。
- 原版点提交还涉及外框、旋转和 AutoFit。此处保留本编辑器外框及 shapeText，不声称复刻整个原生提交流程。进入、取消、无实际变化时不保存，以及首次修改合为一次撤销，是本应用明确采用的事务策略。

## 实现

新增 `src/model/vector-authoring.ts`，在严格参数矩形、统一半径且四边可见的范围内，从当前尺寸和角开关生成未内缩的归一化轮廓。原始存储路径保持不变，直到用户真正修改。

`src/App.tsx`、`src/components/Inspector.tsx`、`src/components/CanvasVectorTools.tsx` 共用该轮廓处理按钮、快捷键、双击命中、节点覆盖层及数值控件。点编辑期间显示当前自适应视图的普通样式，暂时不叠加所选状态或效果预览；这些源字段仍保留。拖动预览显式按自定义路径绘制，不被矩形识别器覆盖。

`src/model/adaptive.ts` 的专用命令仅改目标共享内容的 type/path，首次实际编辑把 box 转为 path，与节点修改合为一条历史记录。普通通用编辑器的类型保护没有放宽。Base、当前及未启用视图的样式、尺寸、效果、嵌套结构和其他控件均保持原样。即使节点恢复成矩形，仍保持自定义身份。

隐藏部分边框和旧独立四角半径的参数重建尚未被完整核对，按钮、快捷键、数值控件和模型提交统一拒绝进入此类节点编辑，防止显示新轮廓却修改旧快照。真正自定义路径及无需参数重建的旧路径继续使用原路径。

## 验证与失败记录

- 浏览器修改前的三条回归均失败：数值 Y 为 50% 而非 30%、首次编辑仍为 box、画布锚点仍位于旧 Y=30。
- 最初一条锚点断言误把 rect 当作 circle，已更正并重新跑原实现，三条均确认失败；两次报告分开保留。
- 汇总器首次误按 TAP 读取 Node 默认的 spec 格式日志，校验停止。实际日志明确记录 698/698、零失败；汇总器已按真实格式及进程退出码检查，未重跑或修改测试结果。旧 `.tap` 同字节副本保留为该命名错误的记录，权威输出为 `.log`。
- 首次集成浏览器 41/43 通过，两个失败均为浮点期望：0.22 与原文件 0.21999999999999997、23.999999999999996 与 24。测试改为逐坐标严格近似比较，其余整文档数据仍精确比较，没有为通过测试改动产品计算。
- 几何 helper 与作者事务分别保留红绿记录。独立复核 407/407，包含 384 原始几何输出、18 跨容器/视图完整保存、2 个真实 Shape300 矩形及 3 项禁入/自定义边界。
- 最终全套单测、698 原生读取器、生产浏览器、同一 ASAR 的桌面检查、截图及 ZIP 文件哈希见 `native-point-editing-verification.json`。早期证据和上个发布包保留在阶段备份中。

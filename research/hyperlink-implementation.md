# 结构化富文本链接 — 实现与边界

日期：2026-10-14。目标 Axure RP 11.0.0.4150；完整复刻仍未完成。

## 本次交付

文字片段以 `linkId` 引用元件内部的 `RichText.links`。每个链接保留独立名称、点击 Case/条件/动作、MouseOver/MouseDown 的七项文字属性；普通外观来自原文字片段。新增链接不猜测蓝色或下划线默认值。作者界面可添加、修改、按选区移除或移除整链接，保留复杂既有交互图；无效 URL 草稿阻止提交，Cancel 无损退出。

复制、粘贴、嵌套面板/中继器、组件定义与实例发布共同重建链接、Case、动作身份，并重映射动作目标与条件引用。普通格式编辑保留链接；在链接内部打字继承身份，边缘打字不扩展链接；跨未链接间隙的替换不继承两端的相同链接。URL 文本是字面值，不接受表达式或随元件复制改写。

预览和离线渲染把连续同链接片段组成一个稳定元素，文字仍用文本节点，支持 Enter 激活与菜单后的焦点恢复。链接命中空动作、Wait 或 Case 菜单时立即阻止父动作；没有匹配 Case 才执行父点击。重复器按实际行实例隔离链接绘制、事件和菜单。单片段、单行 Set Text 保留链接及当前绘制；结构替换去掉链接。动作失败同时回滚链接与自适应绘制状态。

`Open URL` 支持 Current/New window，严格限定字面 HTTP/HTTPS、最长 4096 字符，拒绝凭据、控制字符、反斜线与表达式占位符。离线 Current 跳转自身，New 打开独立窗口。编辑器预览的 Current 复用本次预览独立的目的窗口，避免替换编辑器；New 每次新建。桌面目的窗口使用 sandbox/contextIsolation、不启用 Node、无文件接口 preload，并拒绝非 HTTP(S) 导航及额外弹窗。导航请求不等待页面完成加载才执行后续原型动作。

## 原版依据与导入

- [原版运行时证据](hyperlink-runtime-evidence.md)：实际分发函数的 16 项样式/文字、13 项事件/菜单/Wait、5 项惰性导航实验；导航目标仅记录，没有访问网站。
- [原生格式证据](rich-hyperlink-format-evidence.md)：AxHyperlink 容器、嵌套 AxRun、命名样式双键来源、LinkType Current=1/New=2、WebUrl=0。
- [11 样本导入审计](rich-hyperlink-import-audit.json)：新增 2 个文字元件、2 个链接点击事件/动作。富文本由 632/2,095 元件/片段增至 634/2,149。UI 为 183 顶层 + 22 嵌套、7 事件；Basics 为 173 + 52、2 事件。其他样本计数不变，Icons 仍受页数上限约束。

原生链接的基态保留七项显式 run 属性。只有完全可解码的链接图才导入；任何身份、缓存、引用或动作不受支持时，整个文字元件原子拒绝，不降级成失去交互的普通文本。普通元件的外部 URL 动作复用同样的严格读取链，但本语料没有新增普通事件。原生页面 New-window 跳转仍不映射。

## 验证与已修问题

模型测试覆盖严格解析、身份/引用与编辑和组件工作流；模块/序列化运行时双模式测试覆盖原版操作顺序、无覆盖早退、父状态重新绘制、Set Text、事务回滚和行隔离。浏览器检查使用真实指针/键盘、菜单、保存回读以及离线 HTML，目的地址全部拦截为本地响应。桌面检查针对最终 EXE/ASAR，检查原生 IPC 目的窗口复用、隔离及非法 URL 拒绝，保存三张截图并核对文件哈希。完整实际结果见 [本阶段验证](hyperlink-verification.json)，该报告生成前不据此宣称检查通过。

已修复单片段 Set Text 清空链接绘制缓存的问题，以及失败动作事务遗漏链接/自适应缓存恢复的问题。新增针对性回归检查。原函数对 underline=false + strikethrough=true 的组合会回到片段基态；这项既有装饰转换规则保留，测试夹具若要单独删除线，应只覆盖 strikethrough=true。

## 尚未证明或实现

原版原生截图桥接此前出现 FrameArrived 超时，未做 GUI/逐像素对照。没有将分发函数实验描述为整个原版 GUI 工作流的观察。生成器原始 href/tag 和原版键盘行为仍未知；本产品的可聚焦链接/Enter 是明确的可访问性约定。

直接按住链接移出后的全局 pointer capture、自适应链接缓存完整继承、原生 This 来源、直接对链接 Set Text、任意 HTML/富文本 setter、列表、字符间距、基线/拉伸变体及 Oblique 均未完整复现。原生含未证实 This 链接表达式保持拒绝；作者的链接交互可使用全局变量、明确元件目标和 Item，不能据此认为链接 This 等价于父元件。URL 窗口功能不包含原版完整 player/popup/窗口传参。

原生 `.rp` 仍只读且部分恢复，不能写回。高级元件、完整编辑环境、协作/发布、macOS 和全套 Axure 兼容性仍待完成。只打包单独许可的 Roboto 字体，不打包 Axure 专有代码或素材。

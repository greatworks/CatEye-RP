# 下拉框与列表框实现边界

本阶段补回 Personal information form 中缺失的 Country / Region 与 State / Province，并让作者界面、预览和离线导出使用同一组选项及事件规则。完整 Axure RP 11 重建仍未完成，原版 GUI 和最终生成页像素没有在本阶段对照。

## 文件与来源

- [原始格式证据](rp-dropdown-evidence.md)：11 个保留样本中，共 27 个 ComboBox、1 个 ListBox、2,108 项 SelectObject。
- [原运行函数证据](dropdown-evidence.md)：48 组来自保留 11.0.0.4150 运行资源与其 jQuery 的隔离浏览器探针，包含真实键盘变更；不等同于运行原版编辑器。
- [当前导入审计](dropdown-import-audit.json)：新增 28 个元件，前版已导入的元件 ID 和类型保留。Default 从 27 增至 29；表单库顶层从 540 增至 558，面板内从 430 增至 438。其它样本接受数量不变；Icons 仍超过项目页面数量上限。

国家/地区 197 项，省/州 52 项，首项是单个空格。前者原始选中标记为 `[0]`，后者为 `[]`。导入报告保留原标记，工程写入标准 HTML 单选下拉框的有效选择 `[0]`。单选列表框无标记时保留无选择；多选保留全部标记；单选有多个原标记时最后一个生效。生成器调用顺序、参数和选项文字路径有静态依据，部分属性名字仍混淆，标准 HTML 映射与原字面已解码分开陈述。

## 编辑和运行

`options` 继续保存字面字符串，新增 `selectedIndices` 独立表示选择，明确的 `[]` 表示无选择。空字符串、空格、换行、重复文字和 `[[...]]` 不会被选项编辑器拆分或求值。旧工程省略索引时，通过初始文本的首次精确匹配迁移；新工程明确保存索引。列表框使用 `size=2`，可启用多选。逐项新增、编辑、删除和重排保持选项选择身份，支持保存、撤销和组件复制；列表编辑仅作用于当前元件。

预览和 HTML 都按索引设置 DOM 选择，不用字符串值猜测索引。真实 `change` 信号触发 Selection changed，即使切换的是同名项；普通 input 通知不触发。新增 Set selected option 标量动作以及 Selected option 条件：单选按值选首个匹配项；当前已选同值时保留原索引；找不到值时清空并仍产生变更事件。多选按标量选中所有同名项，保留原 jQuery 数组与字符串宽松相等的行为，例如 `[] == ''` 和 `['A','B'] == 'A,B'` 的短路。

Set Text 对列表无作用。程序设置可以修改禁用或隐藏列表并运行变更处理；用户选择仍服从禁用状态。选择事件同步执行，目标行先求值后按原 FCall 顺序应用；失败动作回滚、递归限制、中继器刷新和页面重载继续由公共运行时管理。菜单同时覆盖用户选择与程序设置，记录实际行内控件的位置并在取消或选择后恢复该控件焦点。

## 仍未覆盖

- 原生 SetSelectedOption 动作的完整序列化载体、复杂目标路径及表达式对象尚未恢复。作者标量动作已实现，类型化数组表达式不在当前模型范围内。
- 原生多选 GetWidgetText 返回数组。现有工程文本表达式仍为字符串接口，以逗号连接选择值；导入拒绝原生多选 GetWidgetText 条件，避免将数组比较冒充字符串比较。GetSelectedOption 读取最上方选中值。
- 原生选项禁用、非字符串选项、非默认继承的 hint/readOnly/type/Submit 及列表 Enter 提交尚不支持。真实样本均为简单字面项、multiple=false、空 Submit；多选与重复项的运行行为由隔离探针和独立工程验证。
- 解析器能识别 GetSelectedOption/OptionLiteral/This 与列表 Focus；事件中存在任何未支持动作或目标时，仍整条拒绝。新增控件不意味着新增完整可执行的原生交互。
- 原 OS 下拉菜单外观、原版编辑器选项对话框、完整富文本动作与云协作仍未完成。
